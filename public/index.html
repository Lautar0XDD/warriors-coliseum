🎮 Conectar con TurboWarp
1
Activar extensión Fetch
En TurboWarp Desktop: Extensiones → Fetch. Permite hacer peticiones HTTP desde Scratch.
2
Guardar la URL de tu API
Guardá la URL de Render en una variable global API_URL:
https://warriors-coliseum.onrender.com
3
Login desde Scratch
Bloque "Login" → POST y guardar el token:
POST {API_URL}/api/login Body: {"username": [usuario], "password": [pass]} → Guardar "token" en variable TOKEN → Guardar "username" en MI_USUARIO
4
Guardar resultado al terminar pelea
Al terminar el combate:
POST {API_URL}/api/match Header — Authorization: Bearer {TOKEN} Body: {"winner": [ganador], "loser": [perdedor]}
5
Ver ranking en el juego (opcional)
GET {API_URL}/api/ranking → Lista de jugadores ordenados por victorias
